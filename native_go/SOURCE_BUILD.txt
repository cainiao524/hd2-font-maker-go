HD2 Font Maker 2.0.0 native source
====================================

The current engine is pinned to frontend 1.3.0 / engine 1.3.7 behavior.
Despite its version number, 2.0.0 keeps this 1.3.7 engine behavior; it is
independent of the historical 1.4/1.5 experiments.

This directory is the hd2font/native Go module. mygoapp is a second module,
hd2font/native/mygoapp, using a local replace directive for the engine.

Build on Windows x64 with Go 1.27.2 or a compatible newer toolchain:
  .\mygoapp\build.ps1 -Go 'C:\Program Files\Go\bin\go.exe' -Test

The GUI executable is mygoapp/bin/HD2FontMaker.exe. The script copies the native
DLLs and atlas executable to the expected relative locations. No Python runtime
is used by the application or needed for a normal Go rebuild.

Optional native-library rebuilds require MSVC x64 build tools and CMake:
- scripts/build-harfbuzz.ps1 downloads and verifies the pinned HarfBuzz archive,
  builds a generated compatibility-patched source copy, and creates the DLL.
- scripts/build-skia.ps1 builds the C ABI bridge against matching Skia headers.
  Supply -SkiaDll with bin/skia.dll and -SkiaRoot with the Skia directory from
  skia-pathops 0.9.2's source distribution. Its archive SHA-256 is
  4b6d8459f6f4a69282cb26fca0c2bb0b321cc58a9bf9cc6579a52a391edc0319.
  Source: https://pypi.org/project/skia-pathops/0.9.2/#files

HarfBuzz is pinned to c7a7457b7385f33178e8cf87615ca077a810bbe7 (14.6.0).
The bridge build records the axisless-CFF2 and sparse-metadata compatibility
changes. Skia algorithms retain their original precision and fill rules.

Most tests use only Go and synthetic fixtures. The native tests require the
DLLs from bin. Optional independent fontTools/Pillow oracles use Python solely
as development verification, never through a product fallback. Private-font
diagnostics require explicit HD2_LOCAL_* environment variables and are skipped
by default. No private font, game snapshot or actual game asset is included.

The CLI entry is cmd/hd2font-build. It uses a saved native inventory with
--snapshot and the same complete pipeline as the GUI. Normal users select their
game directory in the GUI; catalog reads are read-only. The software never
installs a mod or starts a game process.

The scripts that reference the original development workspace's private
benchmarks are not needed to build or use the software. Their source inputs
are intentionally excluded. The public benchmark summary is in the Windows ZIP.

Project-owned code is MIT-licensed. Dependency notices are in LICENSES and
THIRD-PARTY-NOTICES.txt. Keep their copyright and attribution when distributing.

The optional original-registration oracle also needs the original 1.3 Python
source directory, supplied through HD2_V13_REFERENCE_DIR. Normal Go tests and
the product do not need that reference source or a Python runtime.

# Synthetic font fixtures

These eight fixtures contain only tiny authored test shapes and layout rules.
They were created with FontTools FontBuilder, pen APIs, feature builders, and
variation instancing. They are not copied from a personal or game font.

The fixtures cover static TrueType/CFF, a second disjoint character set,
different units per em, a variable TrueType face, and CFF2 conversion. They are
shared by the metadata and HarfBuzz tests. Project-owned fixture data is covered
by the repository's MIT license.

HD2 Font Maker 2.2.2 验证记录

验证日期：2026-11-05。环境：Windows x64，Go 1.27.3，MyGo v0.7.4。
本记录覆盖本地自动化测试、原生字体预览与生成流程、构建和打包检查；不代表游戏内显示验证。

单字体与字体集合
- 单个静态字体默认作为中等（500），不再由字体元数据中的 Light、Regular 或 Bold 决定基准。
- 用户可选择细体 / 常规（400）、中等（500）或粗体（700）；所选档保留原始轮廓，其余两档分别从原字体生成。
- 选择 400 时，500 和 700 分别加粗；默认 500 时，400 变细、700 加粗。
- 界面点击测试验证了默认中等、切换为细体、清除旧的逐档分配、设置保存与恢复、重新导入同一字体保留选择、新字体恢复默认中等。
- 流程测试覆盖不同原始元数据、400 基准、关闭字重匹配，以及每个合成档都从原字体独立处理。
- 原生 DLL 预览测试验证了默认 500、手选 400 / 700 时所选档保持原样，其余档的绘制结果不同。
- 使用包含真实 TTF 字面表的测试 TTC，验证常规 400、中等 500、粗体 700 自动对应，并且没有多余合成；另有界面测试覆盖集合首个字面是粗体的情形。
- 现有同族多文件和可变字体测试随完整测试运行通过。

依赖与构建
- 两个 Go 模块均声明 go 1.27.3；MyGo 由 v0.6.2 更新到 v0.7.4，已执行 go mod tidy。
- 根目录 test.ps1 完整通过：native_go 和 mygoapp 测试、原生流程测试、两模块 go vet，以及 Windows 构建。
- UI 测试覆盖 14 种界面语言；已检查默认中等和手选细体的测试界面截图。
- 生成的 HD2FontMaker.exe 文件版本及产品版本均为 2.2.2.0。
- go version -m 回读 EXE，确认构建工具链 go1.27.3、MyGo v0.7.4 和新增间接依赖 golang.org/x/net v0.59.0。
- 模块缓存完整性校验通过：在临时 Go workspace 中同时声明两个本地模块后，go mod verify 返回 all modules verified。
  直接在 UI 模块校验时，本地 replace 的 hd2font/native v0.0.0 被报告缺少 ziphash；临时 workspace 将其正确视为本地源码，未更改发布模块配置或跳过远程依赖校验。
- 新增 MyGo v0.7.4 和 golang.org/x/net v0.59.0 的许可证副本。

打包
- package.ps1 生成 Windows 便携 ZIP、源码 ZIP 和 SHA-256 清单。
- 打包脚本逐项读取 ZIP 内容并与打包输入比较 SHA-256；源码收集排除工具链、缓存、UserData 和测试输出。
- 本包没有个人字体、游戏资源或已生成的字体 Mod。旧用户可保留 UserData；需要重新生成字体 Mod 才会应用本版逻辑。

验证边界
- 测试使用受控字体样本和构造的 TTC，没有使用老师的实际字体文件。
- 没有启动 HD2、安装生成的 Mod 或核对游戏内三档字体显示。
- 界面截图用于检查控件和字重来源显示；原生预览结果由独立测试验证。

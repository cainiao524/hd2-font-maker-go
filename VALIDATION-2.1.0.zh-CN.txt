HD2 Font Maker 2.1.0 本地交付验证记录
日期：2026-10-26
环境：Windows x64，Go 1.27.3，CGO_ENABLED=0
基准：2.0.0 / e9d52c00206e58d5e0bd65d1ca07e2f3633f3e66

本次代码范围
- 交接包中的深色黄黑界面、响应式布局、字体对照预览、同族多字重、
  400/500/700 手动来源指定、同族补字、可变字体轴、Mod 命名和本地化。
- 修正关闭字重匹配时 TTC/OTC 字面选择器被隐藏、选中 Bold 被换回 Regular。
- 修正可变字体生成时读取未使用的静态同族文件，导致文件缺失时生成失败。
- 程序显示、生成报告及 Windows EXE 的 FileVersion/ProductVersion 统一为 2.1.0。
  Windows 文件版本采用四段形式 2.1.0.0。
- 源码解压重建发现测试临时目录随仓库目录变深而超过原生辅助程序的路径限制。
  构建和测试脚本改用系统临时目录；Go 编译缓存仍保留在源码的 .toolchains 下。

已经完成的验证
1. 完整 test.ps1：原生引擎测试、GUI/生产后端测试、go vet 和 Windows 构建通过。
   test.ps1 启用 HD2_NATIVE_PIPELINE_TEST=1，执行真实原生库的合成字体集成测试。
2. 两项交接残留问题的五个回归分支通过：集合选择器、明确字面与重载保持、
   关闭匹配的静态字体、开启匹配的可变字体，以及缺失有效静态同族文件仍报错。
   这些回归测试在修复前重现了对应缺陷，修复后通过。
3. 原生多字重生成：保留原轮廓及处理轮廓两种设置都通过。
   验证 Regular/Bold 原生字面选择、400 到 500 的差额加粗、Bold 独有字形参与
   繁体中文补字，以及完整替换、输出归档离线回读。
4. 单字体兼容性：使用同一套自制合成字体和资源清单，对 sc/tc/latin 资源群组
   运行字重匹配与轮廓处理的四种开关组合，并与上述 2.0.0 基准比较。
   每组 18 个非报告 ZIP 成员均逐字节一致（四组全部通过）。
   比较时排除 font-build-report.json；报告包含版本、路径等可变化信息。
   这是合成样本的兼容性证据，不是所有用户字体或实际游戏资源的穷尽证明。
5. 14 种界面语言 × 3 种窗口/缩放配置的自动布局与控件检查通过，生成 42 张图；
   另有可变字体控件与字重 300/700 预览图，共 45 张测试图。
   本次实际查看繁中桌面、德文 150% 缩放、日文紧凑布局等代表图，未逐张人工审阅。
   docs/screenshot.png 是离屏渲染的文档示例，使用 Go Regular 与演示路径；
   它不代表实际桌面启动或游戏内截图。
6. 修正旧预览测试对“最后完成的请求一定是游戏字体”的顺序假设：
   当前界面同时渲染自定义字体与游戏字体，测试现在等待两者完成并按用途检查。
   测试记录加锁、退出时取消两路预览；对应交互测试连续执行 100 次通过。

  “Computer Use was not approved to use hd2fontmaker”。实际桌面操作验证未完成。
  自动 GUI 控件测试、离屏渲染及原生引擎测试不能替代这项检查。
